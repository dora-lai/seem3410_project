# SEEM3410 Project: Doctor Staffing Policy in a Hospital Outpatient Clinic

**Course:** SEEM3410 System Modeling and Simulation (CUHK)  
**Team Members:** Lai Sin Hang (`1155213900`), Lee Ka Tung (`1155212062`)

This repository contains the reproducibility package for our discrete-event simulation (DES) study of doctor staffing (`2`, `3`, or `4` doctors) and downstream pharmacy capacity (`1` vs `2` counters) in a two-stage hospital outpatient clinic operating under a 15-minute run-level 90th-percentile (`P90`) doctor waiting-time target.

## 2. Environment Setup & One-Command Reproduction

### Software Requirements
- **Python:** `3.10+`
- **Dependencies:** `numpy>=1.24`, `pandas>=2.0`, `scipy>=1.10`, `matplotlib>=3.7`, `pytest>=7.0`

### Setup & Run
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Regenerate all calibrated parameters, verification checks, CSV tables, and PNG figures (~4 seconds)
python run_all.py

# Run unit and verification tests
pytest -q
```

All stochastic experiments use `numpy.random.SeedSequence(3410)` with four independent RNG substreams per replication (`arrivals`, `priority`, `doctor consultation`, `pharmacy dispensing`) and Common Random Numbers (CRN) across policies, ensuring exact deterministic reproducibility across runs.

## 4. Key Simulation Results (`R = 50` CRN Replications)

| Policy | Doctors / Pharm | Run-Level P90 Doc Wait (95% CI) | Mean Doc Wait | Priority-1 P90 Wait | Mean Pharm Wait | Doc Util. | Scheduled Shift Cost | Overtime-Inclusive Cost |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| **Baseline** | 2 / 1 | **359.8 min** `[350.3, 369.2]` | 175.6 min | 367.5 min | 0.36 min | 99.0% | HK$21,600 | HK$29,818 |
| **Policy A (Recommended)** | **3 / 1** | **11.4 min** `[8.8, 14.0]` | **3.1 min** | **14.1 min** | **0.68 min** | **85.2%** | **HK$30,600** | **HK$30,625** |
| **Policy B** | 4 / 1 | **0.0 min** `[0.0, 0.0]` | 0.06 min | 0.0 min | 0.74 min | 63.9% | HK$39,600 | HK$39,630 |

- **Verification:** Replaying all `300` historical runs (`60,000` patients) across all six scenarios in `data/hospital_sim_6_scenarios.csv` yields **0.0 maximum absolute error** on `DocWaitTime`, `MedWaitTime`, `TotalTimeInHospital`, and continuous-time sample-path Little's Law.
- **Recommendation:** **Policy A (3 doctors, 1 pharmacy counter)** satisfies the `P90 <= 15` min service target (`11.4` min, `95% CI [8.8, 14.0]`), eliminates the `4.6`-hour daily clinic overtime of the 2-doctor baseline (costing only `+HK$807/day` net after overtime), and avoids `+HK$9,005/day` in underutilized capacity under 4 doctors — provided arrival pacing remains regular and demand/service growth stays within `+2%`.
