# SEEM3410 Project: Doctor Staffing Policy in a Hospital Outpatient Clinic

Discrete-Event Simulation (DES) study evaluating doctor staffing levels (2, 3, or 4 doctors) and an optional second pharmacy counter in a hospital outpatient clinic under a 15-minute run-level P90 doctor waiting-time target.

## 1. Software Requirements
- **Python**: 3.10+ (tested on Python 3.13)
- **Packages**: Listed in `requirements.txt` (`numpy>=1.24`, `pandas>=2.0`, `scipy>=1.10`, `matplotlib>=3.7`)

Set up a clean virtual environment and install dependencies:
```bash
python -m venv venv
source venv/bin/activate        
pip install -r requirements.txt
